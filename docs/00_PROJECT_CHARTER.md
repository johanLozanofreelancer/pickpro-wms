
# Proyecto PickPro-WMS(Warehouse Managment System)

    visión general

        El objetivo de PickPro es brindar un mayor control y flujo optimizado del proceso logístico del almacén permitiendo a los usuarios trabajar de manera ordenada, aprovechando al máximo el espacio disponible y ayudando a evitar errores PickPro mas allá de servir para gestionar el proceso en el almacén esta pensado para conseguir una conexión entre las diferentes actividades en la infraestructura de la empresa es decir con los departamentos de compra, ventas, atención al cliente, control de calidad etc, esto con el fin de ofrecer un servicio al cliente mas rápido y eficiente sin mayor complicación
